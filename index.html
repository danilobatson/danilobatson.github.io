How I work

Three habits that come from getting it wrong first.

verify the artifact

A test suite runs against your source. Users run the thing you shipped. Those differ more often than anyone expects — my SDK passed 720 tests while every storage call threw on install, because the test runner supplied a global the published package didn't have. CI now executes the built package.

a guard that can't fail is worse than none

It reports safety you don't have. I found a check whose pattern matched nothing and had been recorded as passing for months. Every guard I add now ships with a fixture proving it goes red.

delete before documenting

Most stale docs aren't underwritten, they're duplicated — the same rule in four files, drifting apart. The fix is usually one owner and three pointers, not a rewrite.
